# 百叶包肉

| 烹饪方式 | 蒸 |
| PDF 页码 | 第 127 页 |

![百叶包肉](./images/127_百叶包肉.jpeg)


## 配料

- 鲜肉百叶包（猪肉、小葱、生姜、大葱、生抽、鸡精等）
- 老鸡汤（老，母鸡、盐、鸡油等）

## 营养成分（每 100g）

| 项目 | 含量 |
|------|------|
| 热量(Kcal) | 100.0 |
| 蛋白质(g) | 189.0 |
| 脂肪(g) | 11.1 |
| 碳水化合物(g) | 15.3 |
| 钠(mg) | 2.2 |

## 制作工艺

1. （1份）将4个百叶包放入上汽后的蒸柜蒸制10分钟，淋入30g老鸡汤，撒上1g葱花出品
